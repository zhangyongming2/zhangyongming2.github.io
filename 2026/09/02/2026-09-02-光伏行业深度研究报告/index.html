光伏行业深度研究报告：从产业链末端看出清与技术迭代

核心判断：光伏行业正处于”高增长时代结束→产能出清→技术路线切换→回收闭环补全”的历史性转折期。2026年全球新增装机首次同比下降，国内上半年装机同比暴跌66%；硅料价格腰斩、库存高企，全行业陷入量价齐缩的深度调整。但与此同时，BC电池快速渗透（一季度出货占比已达66%）、钙钛矿叠层效率突破30%、算电协同催生数据中心第二增长曲线，行业正从”拼规模”转向”拼技术”。2026年是治理攻坚之年，2027年有望迎来拐点，但拐点不等于回暖——不亏了和赚钱是两码事。

一、末端视角：光伏回收从业者看到了什么

知乎用户”永安光伏回收”从产业链最末端——光伏组件回收——的独特视角出发，提供了不同于上游分析师的一线观察。其核心逻辑是：回收端看到的不是到龄退役的板子，而是三五年就出问题的提前报废品，这一现象本身就折射出行业高速扩张期埋下的质量隐患。

1.1 当下三大情况

情况一：高增长时代结束了

彭博追踪光伏20年，2026年全球装机头一次看到同比下降。国内更猛，上半年装机同比掉了66%。CPIA说2027年才可能回暖，之后年增速可能就3%。说白了，从”每年涨”变成”横着走”。

情况二：价格还在跌，但跌价的理由变了

硅料今年从6万跌到3万出头，库存52万吨堆着卖不动。以前降价是大家互相卷（跑量），现在是需求起不来、库存消化不掉。卷好歹还在跑量，现在是量价齐缩，更难受。

情况三：技术上这回是真的在迭代

BC电池一季度出货已经占到66%。爱旭砸16亿多把产线全改ABC，晶澳BC效率28.2%刷新量产纪录。为啥BC突然香了？银价涨的，BC单瓦银耗比TOPCon省65%以上，银价把账拍平了。钙钛矿叠层也在动，六家龙头效率集体冲过30%。

1.2 未来三大判断

短期：出清会是主线

工信部定调2026是治理攻坚之年，上半年组件产量同比降了35%。听着吓人，但产量下降恰恰说明拐点在临近。泼个冷水——拐点不等于回暖，不亏了和赚钱是两码事。

中期：技术分化决定生死

TOPCon市占率要从87%降到50%，BC上位。这个窗口期选错路线的直接出局。新变量：算电协同——数据中心用电量太大，阳光电源预计未来5年数据中心是光伏增速最快的增量市场，可能是第二增长曲线。

长期：回收这环也迟早得补

五年前装的那批板子正在加速退役，2030年全球累计退役近千万吨。现在国内约七成退役组件流进小作坊，正规合规处置率才30%出头。烧了提银卖铝…含氟背板烧出氟化物和铅渗地下水。绿色发电要是被退役回收端的污染了，那可比价格战更伤根基啊。

“光伏死不了，但是现在正是关键时期，从拼规模换成拼技术。2026出清，2027可能拐点，但是跟装机量肯定是不相关了。光伏从来不按你预想的节奏走，但拉长看，方向没错过。”

二、产业链全景与核心公司分析

2.1 产业链结构

光伏产业链遵循”硅料→硅片→电池片→组件→发电系统”的主线路径。结合当前产业实际，可分为**上游（硅料、硅片）、中游（电池片、组件）、下游（逆变器、电站与应用）、末端（回收）**四大环节。

2.2 上游：硅料与硅片

硅料：寡头垄断格局已形成

硅料是本轮周期中产能过剩最严重、价格跌幅最大的环节。多晶硅价格从2022年高点约30万元/吨跌至2026年的3万元/吨出头，行业库存高达52万吨。但行业集中度快速提升——通威与协鑫两家已占据近70%的有效产能。

硅片：双寡头格局，亏损严重

硅片环节由隆基绿能和TCL中环双寡头主导，合计市占率约48%。但2025-2026年硅片价格暴跌导致全行业亏损，TCL中环2025年归母净利润亏损92.64亿元，硅片业务毛利率为-19.44%。

电池片：专业化厂商崛起，技术路线分化

2026年上半年全球电池片出货TOP5为通威、英发睿能、中润光能、捷泰科技、和光同程——值得注意的是，爱旭已退出TOP5，反映出BC技术转型期的出货阵痛。

逆变器：全产业链最赚钱环节

三、行业现状：装机下行、价格磨底、技术迭代

3.1 装机量：20年来首次全球同比下降

2026年是光伏行业具有里程碑意义的一年——不是因为增长，而是因为首次下降。彭博新能源财经追踪光伏产业20多年，2026年是第一次看到全球新增装机下滑。多家机构预测2026年全球新增装机在547-648GW之间，同比下降8-11%。

国内市场更为剧烈：根据国家能源局数据，2026年上半年国内光伏新增装机仅72.07GW，同比下降66%。

但值得注意的是，存量装机仍在创历史。截至2026年7月底，中国光伏发电装机容量达到12.86亿千瓦（1286GW），首次超过煤电，成为中国装机规模最大的电源品类。这意味着光伏已经从”增量主角”转变为”存量主体”。

3.2 价格与库存：从”卷价格”到”量价齐缩”

本轮价格下跌与以往有本质不同。2023-2024年的降价是”以价换量”的内卷；而2026年的降价是**”量价齐缩”**——需求起不来、库存消化不掉，价格越跌越没人买。

积极信号：2026年3月以来，受银价飙升和出口退税取消预期影响，晶科、隆基、天合、晶澳等头部厂商接连上调产品报价，主流组件价格较前期低点涨幅普遍达15-20%。这标志着组件价格底部可能已现。

3.3 技术迭代：BC接棒TOPCon，钙钛矿蓄力

BC电池为什么突然”香了”？

  1. 银价上涨放大成本优势：BC电池正面无栅线，单瓦银耗比TOPCon节省65%以上。在白银价格飙升的背景下，这一成本优势被急剧放大。
  2. 效率天花板更高：TOPCon理论极限28.7%，BC可达29.1%。更重要的是，BC是”平台型技术”，可叠加钙钛矿叠层，将效率推向40%以上。
  3. 量产效率持续突破：晶澳BC效率达28.2%刷新量产纪录；爱旭ABC组件效率最高26%；隆基ACM电池实现规模化投产。
  4. 头部企业All in：隆基2026年BC出货占比目标70-80%，一季度已达66%；爱旭2025年ABC销量14.71GW同比增132%。

钙钛矿叠层：下一个技术奇点

钙钛矿/晶硅叠层电池被视为下一代光伏技术的终极方向。2026年，六家头部企业的叠层电池效率集体冲过30%。上海交大沈文忠教授指出，未来5-8年BC市场份额将从10%提升至50%，而钙钛矿叠层将在2030年后逐步进入产业化阶段。

四、前景研判：短期出清、中期分化、长期闭环

4.1 短期（2026-2027）：出清攻坚，拐点临近但回暖尚远

核心判断：2026年是产能出清的”治理攻坚之年”，产量下降恰恰说明拐点在临近。但拐点不等于回暖——不亏了和赚钱是两码事。

出清的三大驱动力：

  1. 政策强制出清：2027年1月1日新版能耗国标正式实施，TOPCon组件准入门槛为转换效率23.2%。大量低效产能将被强制淘汰。
  2. 市场自发出清：持续亏损迫使二三线企业减产或退出。2026年上半年组件产量同比降35%。
  3. 行业自律出清：八家硅料企业签署”反内卷”倡议，头部组件企业联合涨价，标志着行业从”囚徒困境”转向”合作博弈”。

需要警惕的”假拐点”：价格反弹但需求未跟进（可能只是短期补库存）；头部企业盈利但二三线仍亏损（只是集中度提升）；产能”纸面退出”但实际未拆除（价格回升可能迅速复产）。

4.2 中期（2027-2030）：技术分化定生死，算电协同开新局

核心判断：未来3-5年，技术路线选择将成为决定企业生死的关键变量。TOPCon向BC切换的窗口期（2026-2028）选错路线的企业将直接出局。

技术路线切换的”窗口期陷阱”：

  • All in BC的企业（隆基、爱旭）：如果BC成本下降速度超预期，将获得技术溢价和先发优势；但如果BC良率提升不及预期，可能面临产能闲置风险。
  • TOPCon为主的企业（晶科、天合、通威）：如果TOPCon通过持续提效延长生命周期，可能赢得转型时间；但如果BC成本快速下降，TOPCon产能可能面临减值风险。
  • 双线布局的企业（晶澳）：风险最低，但可能因资源分散而在两条路线上都不占优。

算电协同：光伏的第二增长曲线

AI大模型训练和推理带来的数据中心用电量呈指数级增长。传统电网供电难以满足数据中心对低成本、稳定、绿色电力的需求，光伏+储能的”绿电直供”模式应运而生。阳光电源预计未来5年数据中心将是光伏增速最快的增量市场。

4.3 长期（2030+）：回收闭环补全，绿色属性回归本质

核心判断：2030年前后，全球光伏组件将迎来大规模退役潮，累计退役量近千万吨。回收将从”可选项”变为”必选项”。绿色发电如果被退役回收端的污染反噬，将比价格战更伤行业根基。

回收产业的三大发展方向：

  1. 高值化回收：从简单的”烧了提银卖铝”转向硅、银、铜、铝、玻璃全材料高值回收。全国首条30MW晶硅光伏组件全材料回收中试线已建成。
  2. 梯次利用：对检测合格、仍具备发电能力的退役组件，分级匹配至分布式光伏、储能配套、偏远地区供电等应用场景。
  3. 数字化管理：应用无人机电致发光（EL）成像检测、热成像检测、AI在线监测等方法，精准识别组件健康状态。

政策时间表：2023年发改委发布循环利用指导意见 → 2026年3月工信部等六部门发布综合利用指导意见 → 2027年目标累计综合利用25万吨 → 2030年目标形成大规模退役潮应对能力，资源循环利用产业产值达8万亿元。

六、风险提示

  1. 产能出清不及预期风险：地方政府出于就业和税收考虑对低效产能进行补贴或救助，可能延缓出清节奏。
  2. 技术路线迭代风险：BC对TOPCon的替代速度不确定；如果钙钛矿叠层提前突破，BC可能面临”刚上位就被替代”的风险。
  3. 海外贸易壁垒风险：美国、欧盟等主要市场可能进一步提高关税或设置非关税壁垒。
  4. 原材料价格波动风险：白银价格持续上涨推高组件成本；多晶硅价格如果因出清超预期而快速反弹，可能挤压下游利润。
  5. 回收环节环境合规风险：小作坊粗放回收造成的环境污染可能引发监管收紧，影响整个光伏行业的”绿色”标签。
  6. 电网消纳与电价机制风险：光伏装机持续增长但电网消纳能力不足，可能导致弃光率上升和电价走低。
