昇腾950 × DeepSeek V4 进度全解析：适配已完成，万卡集群下半年量产

发表于2026-05-09|更新于2026-05-09|AI观察
|浏览量:

来源：整理自2026年4月24日 DeepSeek V4 发布信息 + 公开资料

一句话结论

适配早就做完了，现在在等华为把”万卡级 950 超节点”造出来、部署上线，下半年成本和价格会下一个大台阶。

现状（2026-04-24）

  • DeepSeek-V4（Pro / Flash）已经在昇腾950上完成 Day0 级适配，推理可用、性能很高
  • 但950 超节点还没大规模量产交付，所以现在 API 价格贵、吞吐受限
  • DeepSeek 原话：“受限于高端算力，Pro 吞吐有限，预计下半年昇腾950超节点批量上市后降价”

一、昇腾950 芯片发布/量产节奏

昇腾950 分两颗：

芯片 定位 量产时间
950PR（推理主芯片） Prefill + 推理/推荐 2026年3月已量产，Atlas 350 卡已亮相
950DT（训练+Decode） 训练 + Decode 高带宽场景 计划2026年底推出

时间线：

  • 2025-09：徐直军官宣昇腾950 规划
  • 2026-03：950PR 量产，Atlas 350 上市
  • 2026-04-24：DeepSeek V4 发布，官宣昇腾950全系列适配
  • 2026-下半年：950 超节点批量上市
  • 2026-Q4：950DT 训练芯片推出

二、DeepSeek V4 与昇腾950 适配进度（已完成 ✅）

1. 适配状态：已完成、已上线、Day0 级别

  • 4月24日发布会：华为官方公众号发文：“昇腾超节点全系列产品支持 DeepSeek-V4 系列模型”
  • 覆盖：950、A2、A3 全系，同时支持 V4-Pro、V4-Flash
  • 技术路径：从 CUDA → CANN 全栈迁移，重写 200+ 核心算子，用 融合 kernel + 多流并行 优化 Attention，支持 FP4/FP8 量化

2. 实测性能（官方数据）

  • V4-Pro（1.6T 参数）：8K 输入，TPOT≈20ms，单卡 Decode 吞吐 4700 TPS
  • V4-Flash（284B）：8K 输入，TPOT≈10ms，单卡 1600 TPS
  • 对比：950PR 推理性能 ≈ 英伟达 H20 的 2.87 倍，速度较早期提升 35倍，能耗降 40%

三、万卡级集群集成进度

  • Atlas 950 SuperPod：支持 8192 卡集群调度，互联带宽 2TB/s，比上代提升 2.5倍
时间 进度
2026-Q2（现在） 950PR 单卡/小批量服务器已可用
2026-下半年 950 超节点批量上市，万卡级集群开始交付
2026-Q4 950DT 训练芯片上线

四、为什么现在 V4 贵？

  1. 芯片端：950PR 刚量产，良率/产能爬坡期，万卡超节点尚未批量交付
  2. DeepSeek 侧：V4-Pro 是 1.6T 超大模型，现在只能用小规模集群扛流量
  3. 下半年：万卡集群上线 → 成本腰斩、价格下调
